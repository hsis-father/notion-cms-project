# PRD: 개인 개발 블로그 (Notion CMS 기반)

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 개인 개발 블로그 |
| 목적 | Notion을 CMS로 활용한 개인 기술 블로그 |
| 작성일 | 2026-05-31 |
| 버전 | v1.0.0 |

### 1.1 배경 및 목적

Notion을 콘텐츠 관리 시스템(CMS)으로 활용하여 별도의 관리자 페이지 없이 익숙한 Notion 환경에서 글을 작성하고, 작성된 글이 자동으로 블로그에 반영되는 개인 기술 블로그를 구축한다.

### 1.2 CMS로 Notion을 선택한 이유

- Notion에서 글을 작성하면 자동으로 블로그에 반영되어 관리 편의성 극대화
- 별도의 백엔드/DB 구축 불필요
- 풍부한 Notion 에디터 기능 활용 가능 (코드 블록, 이미지, 표 등)
- Notion API를 통한 안정적인 데이터 연동

## 3. 주요 기능 (Features)

### 3.1 핵심 기능

| # | 기능 | 설명 | 우선순위 |
|---|------|------|----------|
| F-01 | 글 목록 조회 | Notion 데이터베이스에서 발행된 글 목록 가져오기 | 필수 |
| F-02 | 글 상세 페이지 | 개별 글의 전체 내용 표시 | 필수 |
| F-03 | 카테고리 필터링 | 카테고리별 글 목록 필터링 | 필수 |
| F-04 | 검색 기능 | 글 제목/내용 기반 검색 | 필수 |
| F-05 | 반응형 디자인 | 모바일/태블릿/데스크탑 지원 | 필수 |

### 3.2 기능 상세

#### F-01: 글 목록 조회
- Notion API를 통해 `Status = 발행됨` 인 글만 노출
- 최신순 정렬 (Published 날짜 기준)
- 각 목록 카드에 표시: 제목, 카테고리, 태그, 발행일, 요약 (첫 문단)

#### F-02: 글 상세 페이지
- Notion Page Content를 HTML로 변환하여 렌더링
- 지원 블록 타입: 단락, 제목(H1~H3), 코드 블록, 이미지, 목록, 인용구, 구분선
- 이전 글 / 다음 글 네비게이션

#### F-03: 카테고리 필터링
- 상단 또는 사이드바에 카테고리 목록 표시
- 선택한 카테고리에 해당하는 글만 필터링하여 표시

#### F-04: 검색 기능
- 검색창에 키워드 입력 시 제목 기준으로 검색
- 검색 결과 실시간 반영 (클라이언트 사이드 필터링)

#### F-05: 반응형 디자인
- 모바일(360px~), 태블릿(768px~), 데스크탑(1024px~) 대응
- Tailwind CSS 반응형 유틸리티 활용

## 5. Notion 데이터베이스 구조

### 5.1 데이터베이스 속성 (Properties)

| 속성명 | 타입 | 설명 | 비고 |
|--------|------|------|------|
| Title | title | 글 제목 | 필수 |
| Category | select | 카테고리 | 예: Frontend, Backend, DevOps |
| Tags | multi_select | 태그 | 예: React, TypeScript, Next.js |
| Published | date | 발행일 | 정렬 기준 |
| Status | select | 상태 | `초안` / `발행됨` |
| Content | page content | 본문 | Notion 페이지 내부 블록 |

### 5.2 Status 값 정의

| 값 | 설명 | 블로그 노출 여부 |
|----|------|----------------|
| 초안 | 작성 중인 글 | 노출 안 함 |
| 발행됨 | 완성된 글 | 노출 |

## 8. 구현 단계

### Phase 1: 환경 설정 (1일)

1. Next.js 15 프로젝트 생성 (`create-next-app`)
2. TypeScript, Tailwind CSS, shadcn/ui 설정
3. `@notionhq/client` 패키지 설치
4. `.env.local` 설정 (`NOTION_API_KEY`, `NOTION_DATABASE_ID`)

### Phase 2: Notion 연동 (1일)

1. Notion Integration 생성 및 API 키 발급
2. Notion 데이터베이스 생성 및 구조 설정
3. Notion API 클라이언트 초기화 (`lib/notion.ts`)
4. 글 목록 조회 함수 구현 (`getPostList`)
5. 글 상세 조회 함수 구현 (`getPostBySlug`, `getPostContent`)

### Phase 3: 글 목록 페이지 구현 (1일)

1. `PostCard` 컴포넌트 구현
2. 카테고리 필터 컴포넌트 구현
3. 검색창 컴포넌트 구현
4. 홈 페이지 (`app/page.tsx`) 구현

### Phase 4: 글 상세 페이지 구현 (1~2일)

1. Notion 블록 렌더러 구현 (`NotionRenderer`)
2. 지원 블록 타입 구현 (단락, 제목, 코드, 이미지 등)
3. 글 상세 페이지 (`app/posts/[slug]/page.tsx`) 구현
4. 이전/다음 글 네비게이션

### Phase 5: 스타일링 및 최적화 (1일)

1. 전체 UI 스타일 정리 (shadcn/ui 컴포넌트 활용)
2. 반응형 레이아웃 점검
3. 메타데이터 설정 (SEO 기본)
4. Vercel 배포
